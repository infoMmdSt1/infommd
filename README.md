# VC PRO — تغییر صدا با منوی شناور (اندروید)

## ساخت APK

### راه ۱: Android Studio
1. پوشه SampVoice رو توی Android Studio باز کن (File → Open).
2. صبر کن Gradle Sync تموم بشه.
3. Build → Build APK(s) → فایل `app/build/outputs/apk/debug/app-debug.apk`.

### راه ۲: بدون نصب چیزی روی کامپیوتر (GitHub Actions)
1. توی github.com یه repository خالی بساز.
2. تمام محتوای این پوشه (با پوشه `.github`) رو آپلود کن.
3. تب Actions → «Build APK» → بعد از تموم شدن، فایل `VC-PRO-APK` رو از Artifacts دانلود کن (داخلش app-debug.apk هست).

## استفاده
1. برنامه رو باز کن، «فعال‌سازی منو» رو بزن و اجازه‌های «نمایش روی سایر برنامه‌ها» و میکروفون رو بده.
2. منوی کوچک (میکروفون + فلش) روی صفحه میاد. تپ = باز شدن، ✕ = کوچیک شدن، کشیدن = جابجایی.
3. دکمه‌ها: صدای کلفت / بم / نازک، نویز صدا (هر تپ یه سطح)، افزایش و کاهش صدا، اسلایدر بلندی، غیرفعال/فعال کردن، ریست، پخش تست.

## نکته درباره رسوندن صدا به سمپ
اندروید (بدون روت) اجازه نمیده برنامه میکروفون مجازی بسازه. برنامه صدا رو پردازش و از بلندگو پخش میکنه و میکروفون بازی اون رو میگیره (بلندی رو کم نگه دار تا ویز ویز نکنه). با روت و ماژول میکروفون مجازی می‌شه مستقیم وصلش کرد.
